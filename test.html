📋 强制复制 - 功能测试页面

此页面包含 6 种常见的网页复制限制方式。安装「强制复制」扩展后，点击扩展图标启用当前站点，然后刷新此页面，尝试选中并复制以下所有文字。

测试 1：CSS user-select: none

CSS: user-select: none !important;
这段文字被 CSS user-select: none 保护。正常情况下你无法选中它。安装扩展后应该可以自由选中复制。这是一段测试文字，包含中文和 English mixed content。
✅ 如果你能选中这段文字，说明 CSS 层防护解除成功

测试 2：JS addEventListener 阻止复制

JS: document.addEventListener('copy', e => e.preventDefault())
这段文字被 JavaScript 事件监听器保护。即使你能选中文字，按下 Ctrl+C 时复制操作会被阻止。安装扩展后应该可以正常复制。
✅ 如果你选中文字后按 Ctrl+C 能复制到剪贴板，说明事件拦截成功

测试 3：内联事件属性阻止复制

HTML: oncopy="return false" oncontextmenu="return false"
这段文字通过 HTML 内联事件属性保护。oncopy、oncut、onpaste、oncontextmenu、onselectstart 全部被设置为 return false。安装扩展后应该可以正常复制和右键。
✅ 如果你能选中、复制并右键这段文字，说明内联事件清除成功

测试 4：禁止右键菜单

JS: document.addEventListener('contextmenu', e => e.preventDefault())
这段文字所在区域禁止右键菜单。正常情况下右键点击不会弹出菜单。安装扩展后应该可以正常右键。
✅ 如果你能在这段文字上右键弹出菜单，说明右键菜单拦截成功

测试 5：透明伪元素覆盖层

CSS: ::after { content: ''; position: absolute; top:0; left:0; right:0; bottom:0; z-index:1; }
这段文字上有一个透明的伪元素覆盖层。正常情况下鼠标点击会被覆盖层拦截，无法选中文本。安装扩展后应该可以穿透覆盖层选中文字。
✅ 如果你能选中这段文字，说明覆盖层防护被突破

测试 6：动态添加保护（模拟 SPA）

JS: 动态插入带保护属性的新元素

点击下方按钮，会动态插入一段被保护的新文字。扩展的 MutationObserver 应该能自动清除新元素上的保护属性。

✅ 如果动态插入的文字也能被选中复制，说明 MutationObserver 工作正常
