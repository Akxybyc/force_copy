# force_copy
强力复制
解除网页复制限制，支持按站点开关控制。一键启用，自由复制任何网页内容。支持 CSDN 等高级防护网站
无需再为登录烦恼，打开即可复制

一、使用教程：（此处以Edge为例）
1.下载扩展zip解压缩
2.打开edge或任意可用插件浏览器
3.打开扩展管理页面
4.打开开发者选项
5.加载解压缩的扩展
6.选择force-copy文件夹

二、注意事项：
如果提示清单文件丢失
1.进入 Desktop/force-copy/
2.选择里面的 force-copy 文件夹
3.或者把里面的 force-copy 文件夹直接移到桌面，替换掉外层的
